# Student Management System - JDBC

A console-based Student Management System developed using Java, JDBC, PostgreSQL, and Maven.

## Features

- Add Student
- Update Student
- Delete Student
- Search Student by Roll Number
- Display All Students
- Exit
- PostgreSQL database integration
- JDBC-based database operations
- Secure database password using environment variables

## Technologies Used

- Java
- JDBC
- PostgreSQL
- Maven
- IntelliJ IDEA
- Git & GitHub
